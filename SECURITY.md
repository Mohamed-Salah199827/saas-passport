# Security policy

The project is pre-alpha and has no supported releases. Report security issues affecting the current default branch via [GitHub private vulnerability reporting](https://github.com/Mohamed-Salah199827/saas-passport/security/advisories/new). If private reporting is unavailable, use [GitHub Support](https://support.github.com/contact) for help reaching the maintainer privately.

Include the affected commit, impact, and minimal reproduction using synthetic data. Redact tokens, customer data, account identifiers, and request bodies. Keep reports private while maintainers triage impact and coordinate disclosure. Maintainers will share remediation and disclosure plans through the private report when available.

If a credential was exposed, revoke or rotate it with its issuing service immediately.
