# Code of Conduct

This project welcomes contributors of all backgrounds and experience levels. Give specific, constructive feedback, respect stated boundaries, credit others' work, and discuss technical disagreements without personal attacks.

Harassment, threats, discriminatory language, unwanted sexual attention, impersonation, and sharing another person's private information without consent are unacceptable. This applies in the project's issues, pull requests, discussions, and other spaces where someone represents the project.

Report incidents privately using GitHub's abuse reporting tools. For repository content, open the content menu and select **Report content**. For account behavior or where a maintainer is involved, use [GitHub Support](https://support.github.com/contact/report-abuse). GitHub handles these reports under its own policies. Maintainers may hide content, lock conversations, restrict participation, or block accounts based on severity. Keep incident details private and avoid retaliation.
