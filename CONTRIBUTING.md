# Contributing

Read the [contributor guide](docs/CONTRIBUTOR-GUIDE.md) and [code of conduct](CODE_OF_CONDUCT.md). Select a planned item from the [PR roadmap](docs/PR-ROADMAP.md) with completed dependencies, or open a feature proposal explaining the use case. Link the item in your PR and describe scope, compatibility, and verification. Include focused tests and updates to the relevant specification in the same PR.

Use fictional fixtures. Report vulnerabilities and accidental disclosure through the [security policy](SECURITY.md).
